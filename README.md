# 🛠️ ER1991 Smart Investment Radar PRO — إصدار GitHub (v7.0)

نفس أداة تحليل الأسهم التي تعمل على Google Colab — منقولة إلى GitHub **دون أي تغيير في منطق الكود أو الحسابات أو التصميم أو النتائج**.

تحليل فني متعدد الأطر + تحليل مالي عميق (Piotroski / Altman / Beneish) + القيمة العادلة بـ7 نماذج + خطة دخول وأهداف + تقارير تفاعلية (HTML / Excel / CSV / PDF / PNG).

> ⚠️ أداة مساعدة في قراءة وفحص الأسهم والقرار الاستثماري، **وليست توصية بالشراء أو البيع**.

---

## 🚀 التشغيل السريع

### الطريقة 1 — Codespaces (واجهة تفاعلية مثل كولاب تماماً)
1. اضغط زر **Code** الأخضر ← تبويب **Codespaces** ← **Create codespace on main**.
2. انتظر دقيقة حتى ينتهي التثبيت التلقائي (سجل الطرفية يعرض: «كل شيء جاهز»).
3. افتح الملف **`ER1991_Radar.ipynb`** واضغط ▶ على الخلية الأولى — ستظهر نفس واجهة كولاب.
4. أدخل الرموز واضغط «بدء الفحص والتحليل الشامل»، ثم نزّل التقارير من مجلد `ER1991_Reports` في شجرة الملفات.

### الطريقة 2 — GitHub Actions (بدون فتح أي بيئة)
1. تبويب **Actions** ← **ER1991 Radar** ← **Run workflow**.
2. اكتب الرموز (أو اتركها فارغة ليُقرأ `config.json`) ثم اضغط **Run workflow**.
3. بعد الانتهاء نزّل المرفق **ER1991_Reports** من صفحة التشغيل — ويُحفظ أيضاً في مجلد `reports/` بالمستودع، وينشر التقرير التفاعلي على **GitHub Pages**.

### الطريقة 3 — طرفية محلية
```bash
pip install -r requirements.txt
python run_radar.py            # يقرأ config.json
```

## 📁 ملفات المستودع

| الملف | وظيفته |
|---|---|
| `er1991_radar.py` | الكود الأساسي الكامل (مطابق لإصدار كولاب v7.0) |
| `run_radar.py` | مشغّل سطر الأوامر — يستدعي نفس `run_scan` والتصديرات |
| `config.json` | الرموز والإعدادات الافتراضية للتشغيل الآلي |
| `ER1991_Radar.ipynb` | دفتر Jupyter بواجهة الأداة التفاعلية (Codespaces) |
| `requirements.txt` | تبعيات بايثون (نفس حزم كولاب) |
| `.github/workflows/radar.yml` | التشغيل التلقائي على Actions (يدوي + مجدول اختياري) |
| `.devcontainer/` | تثبيت تلقائي عند فتح Codespace |
| `docs/` | دليل التشغيل الكامل PDF |

## ⚙️ تعديل الرموز والإعدادات
كل شيء في **`config.json`**: الرموز، السوق، المؤشر المرجعي، أسلوب الاستثمار، رأس المال، لغة التقارير، الصيغ المصدَّرة، وتجاوزات لوحة الإعدادات (القيمة العادلة/الحارس/الأوزان) داخل مفتاح `settings` — نفس مفاتيح الواجهة مثل `fvMarketPE` و`fvW.pe` و`fvExt`.
